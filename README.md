# Трекер расходов

Программа читает расходы из CSV и показывает суммы по категориям и по месяцам.

## Начало работы

Требуется Python 3.12+. Запустите из этой папки:

```bash
python expense_tracker.py expenses.csv
```

На некоторых системах используйте `python3` вместо `python`. Пока шаблон выводит только сообщение о заготовке: реализуйте функции в `expense_tracker.py`.

CSV сохранён в UTF-8. Формат: заголовок `date,category,amount`, дата `YYYY-MM-DD`, сумма с точкой в качестве десятичного разделителя. Используйте модуль `csv` стандартной библиотеки.

## Пример ожидаемого вывода

```text
По категориям:
Аренда: 170000.00
Еда: 11400.00
Кафе: 15700.00
Обучение: 19500.00
Продукты: 61100.00
Развлечения: 11500.00
Связь: 14000.00
Транспорт: 7800.00

По месяцам:
2026-01: 26700.00
2026-02: 37900.00
2026-03: 124900.00
2026-04: 121500.00
```

Порядок категорий может отличаться.
